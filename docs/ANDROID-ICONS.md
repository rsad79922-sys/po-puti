# Фирменный значок Android

Причина прежнего значка: `cap add android` создаёт новые mipmap/adaptive ресурсы
Capacitor, а prepare-android раньше не заменял их. Иконки PWA сами по себе не
становятся значком APK.

Единственный источник нового значка — оригинальное изображение владельца
`native/branding/launcher-source.jpg`. SHA-256:
`2470bdf52a712ac5422aeafae7efa8e61b1d2a118a380d5de6ffe403e024ac80`.
Рисунок не перерисовывается. `scripts/prepare-launcher-icons.mjs` вызывается
из prepare-android при каждой сборке и готовит PNG mdpi–xxxhdpi, круглые PNG
для старых launcher, adaptive XML/foreground с безопасной областью и фирменный
splash. Уникальные имена foreground исключают перекрытие старым drawable-v24.

Проверки: tests/launcher-icons.mjs — источник, размеры, прозрачные углы круга,
adaptive ссылки/безопасная область, splash и повторная генерация. Android
LauncherIconAssertions проверяет Drawable, реально разрешённый PackageManager,
включая adaptive тип и наличие тёмного, бирюзового и белого цветов. Проверка
включена в обычные native тесты и в тест самого подписанного release APK.

Пакет ru.poputi.app и постоянный релизный ключ сохраняются. Выпуск с новым
значком должен иметь versionCode выше 5. Пользователи APK с сайта обновляются
вручную: скачать новый файл по прежней ссылке и установить поверх старой версии.
Удалять приложение не нужно. Обновление сайта не заменяет уже установленный APK
и не меняет значок на устройстве без установки новой сборки.
